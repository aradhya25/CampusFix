# CampusFix client

This React/Vite application is the CampusFix browser client. See the repository [README](../README.md) for the full project overview, backend setup, environment variables, API, and verification instructions.

## Run locally

Install dependencies with `npm install`, then start the development server with `npm run dev`. Set `VITE_API_URL` in `.env.local` when the API is not at the default `http://localhost:5000/api`.

## Checks

- `npm run build` creates the production client bundle.
- `npm run lint` runs ESLint.
